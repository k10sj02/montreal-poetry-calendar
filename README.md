# Montréal Poetry & Literary Calendar

An automatically updated, subscribable calendar covering poetry readings, literary launches, book talks, open mics, clubs, and related events in Tiohtià:ke/Montréal.

Sources include [Where Poets Read](https://wherepoetsread.ca/), [Jay's List](https://www.discordiareview.com/), [Cult MTL Literary](https://cultmtl.com/event_listing_category/literary/), [Librairie Résonance](https://librairieresonance.com/en/pages/evenements), and filtered library and cultural listings from [Montréal Has Things](https://montreal.hasthings.com/).

The feed refreshes every six hours and includes event descriptions, venue information when published, source links, stable identifiers, and cancellation handling.

This project is independent and is not affiliated with Where Poets Read or the listed organizers.
