# Montréal Poetry Calendar

An automatically updated, subscribable calendar generated from [Where Poets Read](https://wherepoetsread.ca/), covering poetry readings and related events in Tiohtià:ke/Montréal.

The feed refreshes every six hours and includes event descriptions, venue information when published, source links, stable identifiers, and cancellation handling.

This project is independent and is not affiliated with Where Poets Read or the listed organizers.
